- Never forget these **development principles**:
  - **KISS (Keep It Simple, Stupid):** Simplicity should be a key goal in design, and unnecessary complexity should be avoided
  - **DRY (Don't Repeat Yourself):** Every piece of knowledge must have a single, unambiguous representation within a system
  - **YAGNI (You Aren't Gonna Need It):** Always implement things when you actually need them, never when you just foresee that you need them
  - **Component Composition over Inheritance:** Build complex UIs from simple, reusable components
  - The best code is no code at all. Every line of code is a liability — Jeff Atwood. Write less, achieve more!
